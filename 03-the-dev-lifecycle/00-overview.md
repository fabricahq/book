There are two modes for producing things:

1. Foundations
2. Features & fixes

In foundations mode, you need to prototype to see if what you're building is even useful. Once you verify that it is, you need to set your tech stack, and high-level architecture. Once that's set, then you can build your first feature. 

In foundations mode, our deliverables are:

- A UI prototype
- A vision for what to build
- A tech stack
- An architecture

You might do foundations mode for a brand new system, for a new feature, or something in between.

In features & fixes mode, our deliverables are:

- a new feature
- an improvement
- a bug fix

Each mode has their own lifecycle

## Foundations

1. Explore
2. Plan
3. Slice

## Features & fixes

1. Spark
2. Foundations Mode (if needed)
   1. Explore
   2. Plan
   3. Slice
3. Build
4. Validate
5. Merge
6. Deploy
7. Operate
