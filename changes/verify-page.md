title: Added a page on verifying the agent's work
---

Verification now has its own stage in delivery, between building and validating.

- [Verify](../03-the-dev-lifecycle/03-deliver/03-verify.md): covers how an agent checks its own work before you see it, with end-to-end tests, property-based tests, fast feedback loops, and letting the agent drive your app.
- [Build](../03-the-dev-lifecycle/03-deliver/02-build.md): now focuses on telling the agent how to build with Syllabus, formerly Code Rules, and hands verification to Verify.
- [Plan](../03-the-dev-lifecycle/03-deliver/01-plan.md): now starts a checklist of what's must review, such as layers, data flows, schemas, and vocabulary, and what's nice to review.
- [Validate](../03-the-dev-lifecycle/03-deliver/04-validate.md): now covers checks by something other than the implementing agent, such as you or a fresh reviewer agent, where Verify covers the agent checking itself, and reviewing decisions that departed from the design tree.
- [Toolbox](../90-toolbox/index.md): now lists tools I need, starting with a test visualizer for reviewing the tests an agent proposes.
