This book is an aggregation of insights I've learned, both from building my own software factory and from reading and watching the insights of others.

I want to give credit where it's due, so I make every effort to cite the original source of an insight. But that's harder than it sounds. Some ideas are being discovered independently by multiple people at the same time, and things change so fast that it can be hard to remember where an idea came from.

If you see an idea that should be attributed to someone, [let me know](https://github.com/fabricahq/book/issues/new?template=attribution.md) and I'll make sure to make the update.
