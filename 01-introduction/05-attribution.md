This book is a summary of what I've learned, both from building my own software factory and from seeing the insights of others.

I want to give credit where it's due, so I make every effort to cite the original source of an insight where possible.

If you think I've made a mistake and you see an idea that you think should be attributed to someone, [let me know](https://github.com/fabricahq/book/issues/new?template=attribution.md) and I'll make sure to fix it.
